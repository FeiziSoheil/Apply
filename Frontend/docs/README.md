# مستندات فنی و راهنمای دامنه سامانه Apply

این پوشه شامل کلیه مستندات معماری، قراردادهای داده، استانداردهای API، طراحی دامنه‌ها و راهنماهای استقرار سامانه جامع اعزام دانشجو و مهاجرت تحصیلی است.

---

## نقشه راه و فهرست مستندات

```
Frontend/docs/
├── openapi.yaml               # مشخصات کامل OpenAPI 3.1 تولیدشده از Zod
├── api-conventions.md         # قراردادهای عمومی REST، ساختار خطاها و صفحه‌بندی
├── student-panel-domain.md    # معماری، مراحل پرونده و چرخه حیات پورتال دانشجو
├── crm-domain.md              # خطوط لوله سرنخ‌ها (Leads)، بورد کانبان و ارتباطات
├── content-model.md           # مدل محتوای هیبرید (داده ساختاریافته + RichContent)
├── content-editor.md          # ویرایشگر محتوای بصری Tiptap و نودهای سفارشی
├── crud-kit.md                # استاندارد و کیت توسعه پنل‌های CRUD مدیریت
├── mocking.md                 # معماری Mock Service Worker و شبیه‌سازی API
├── settings-binding.md        # اتصال تنظیمات سیستم و خط لوله به کنترل‌ها
├── deployment-notes.md        # پیکربندی محیط تولید، متغیرها و پراکسی بک‌اند
└── university-image-prompts.md # پرامپت‌ها و مشخصات تصاویر دمو دانشگاه‌ها
```

## شرح محتوای هر سند

### ۱. قراردادها و مشخصات رابط برنامه‌نویسی
- **[openapi.yaml](openapi.yaml):**  
  سند استاندارد OpenAPI 3.1 شامل بیش از ۳۰۰ اندپوینت، مدل‌های درخواست و پاسخ، کدهای وضعیت و ساختار پارامترها که مستقیماً از قراردادهای Zod در `src/contracts` بازتولید می‌شود (`npm run contract:generate`).
- **[api-conventions.md](api-conventions.md):**  
  استانداردهای طراحی API، ساختار Envelope پاسخ‌ها، خطاهای RFC 7807، نحوه ارسال توکن‌های اعتبارسنجی (Bearer Token و Session Cookie)، قوانین فیلترینگ و مرتب‌سازی و صفحه‌بندی مبتنی بر مکان‌نما (Cursor/Offset Pagination).

### ۲. طراحی دامنه‌های تخصصی
- **[student-panel-domain.md](student-panel-domain.md):**  
  مستند جامع پورتال اختصاصی دانشجو با تمرکز بر معماری Mobile-First، چرخه حیات متقاضی (از سرنخ تا عقد قرارداد و اخذ ویزا)، مراحل پرونده تحصیلی، الزامات مدارک، سیستم مقایسه دانشگاه‌ها (Shortlist) و فرآیند پرداخت.
- **[crm-domain.md](crm-domain.md):**  
  مستند دامنه ارتباط با مشتریان و مدیریت مؤسسه؛ شامل فرآیند ثبت سرنخ (Lead Ingestion)، انتقال بین مراحل کانبان، ثبت دلایل ریزش (Lost Reasons)، سیستم فعالیت‌ها و یادداشت‌های تماس و قوانین جداسازی پرونده‌های مشاورین.

### ۳. سیستم مدیریت محتوا و ویرایشگر غنی
- **[content-model.md](content-model.md):**  
  تشریح مدل هیبرید تفکیک داده‌های ساختاریافته (قابل فیلتر و جستجو) از متن آزاد (RichContent) جهت جلوگیری از آسیب‌پذیری‌های امنیتی XSS و حفظ یکپارچگی استایل‌ها.
- **[content-editor.md](content-editor.md):**  
  راهنمای پیاده‌سازی و نودهای سفارشی ویرایشگر متن Tiptap شامل باکس‌های هشدار (Callout)، آکاردئون‌ها، مراحل گام‌به‌گام (Steps)، دکمه‌های اقدام (CTA) و نحوه اعتبارسنجی درخت JSON.
- **[crud-kit.md](crud-kit.md):**  
  الگوی استاندارد ساخت صفحات مدیریتی در پنل ادمین (جدول‌ها، فرم‌های مودال، دیالوگ‌های حذف، به‌روزرسانی‌های خوش‌بینانه و بازخورد با Sonner).

### ۴. شبیه‌سازی، توسعه و استقرار
- **[mocking.md](mocking.md):**  
  راهنمای جامع کار با MSW (Mock Service Worker)، ساختار دیتابیس رابطه‌ای در حافظه (با پشتیبانی از ذخیره‌سازی در LocalStorage)، کلاینت احراز هویت دمو و سناریوهای آزمایشی (تأخیر شبکه، ۵۰۰، تعارض نسخه).
- **[settings-binding.md](settings-binding.md):**  
  راهنمای اتصال تنظیمات خط لوله CRM، ظرفیت و ساعات در دسترس بودن مشاورین به کامپوننت‌های فرم.
- **[deployment-notes.md](deployment-notes.md):**  
  نکات حیاتی برای دیپلوی، تنظیم متغیرهای محیطی، گارد مسدودکننده ماک در محیط Production و پیکربندی `API_PROXY_TARGET` جهت بازنویسی مسیرهای API.

## نحوه به‌روزرسانی مستندات

هنگام اعمال تغییرات بر روی قراردادهای سامانه (`src/contracts/`):
```bash
# بازتولید فایل openapi.yaml
npm run contract:generate

# اعتبارسنجی انطباق ماک‌ها با قراردادها
npm run mock:smoke
```
